## npm Audit Findings

At the time of this review:

13 vulnerabilities were reported:
- 7 moderate
- 6 high

These are JavaScript verifier/dependency findings.
They are NOT equivalent to 13 vulnerabilities in the ANGRY Rust/on-chain program.

No `npm audit fix --force` was applied because npm proposed breaking dependency changes/downgrades that would invalidate the verified baseline.

### bigint-buffer

bigint-buffer@1.1.5 is reachable through:

@solana/spl-token
-> @solana/buffer-layout-utils
-> bigint-buffer

The tested Termux/Android environment failed to load the native bigint-buffer binding and emitted:

"Failed to load bindings, pure JS will be used"

Source inspection confirmed that in this condition `toBigIntLE()` and `toBigIntBE()` use the pure JavaScript fallback instead of the native converter.

Therefore the native execution path was NOT active in the verified Termux baseline.

Important:
This conclusion is environment-specific.
If the verifier is later run where the native binding loads successfully, bigint-buffer risk must be reassessed.

### toml

toml@3.0.0 is installed through:

@pump-fun/pump-swap-sdk
-> @coral-xyz/anchor
-> toml

Anchor's workspace module imports `toml`.

Source inspection showed `toml.parse()` is called when Anchor workspace program lookup is accessed.

No Anchor workspace usage was found in:
- verify-part3.mjs
- @pump-fun/pump-swap-sdk

Therefore the vulnerable TOML parsing path was not observed as reachable from the current Part 3B verifier flow.

The package remains present and should continue to be monitored.

### stream-json

stream-json is installed through:

@solana/web3.js
-> jayson
-> stream-json

Jayson statically references stream-json utilities.

The package was not observed in the precheck module-load trace.

This does NOT prove it can never be reached during every verifier mode.
It remains a transitive dependency risk that should be re-evaluated when dependencies change.

### uuid

The dependency tree contains uuid versions through Solana RPC/WebSocket dependencies.

Jayson statically uses UUID v4.

The reported advisory path inspected during this review did not match the observed Jayson UUID v4 call site.

This remains a dependency advisory and should be reconsidered when the Solana web3 dependency is upgraded.

## Runtime Artifacts

`part2-plan.json` is generated by `buildPlan()`.

It is written as runtime output and is not read back by the verifier.

It is excluded from Git together with local package backup files.

The legacy filename is intentionally not changed in the verified verifier source because modifying it would change the SHA-256 of the already verified baseline.
