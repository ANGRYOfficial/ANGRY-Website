Architecture

Multi-chain without pretending every chain is the same.

ANGRY can share one interface while keeping EVM and Solana logic separated where their wallets, token standards or NFT systems differ.

EVM path

Ethereum, Base, Robinhood Chain, BNB Smart Chain, Arbitrum and Polygon can use EVM-compatible wallet and contract patterns when the specific tool has that network enabled.

Solana path

Solana uses its own token and wallet architecture. ANGRY keeps Solana-specific implementation separate instead of routing Solana through ERC logic.
